## 一、这是什么（30 秒版）

一套**给 AI 执行的 AIGC 视听创作规则库**，把「做剧」拆成一条可复用的工业管线，解决三件事：

1. **不漂移** —— 角色 / 场景 / 道具**先锁定再进分镜**（Asset-First），跨镜跨集一致性有据可依；
2. **不返工** —— 前置锁 + 投喂必查清单 + P0~P2 独立门禁 + 稿件级机检，把错误拦在生成之前；
3. **能直接投喂** —— 输出**七段式**结构化提示词，整组复制即可喂视频模型；走 H3 时自动转六段式。

**核心理念：用户看到 5 个步骤，AI 内部跑 100 条规则。**

```
立项锁定 → 赛道分流 → 五阶门控剧本 → 资产锁定 → 文武双模分镜 → 提示词封装 → 独立质检 → 离线看板
```

**本包不持有图**：交付物 =「提示词 + 接线说明书」。图由用户在外部平台（即梦 / Seedance / 豆包等）自行生成并持有，默认**不调用任何出图工具**。

## 二、硬门 ①：六道前置锁 + I 画风锁（最高优先级）

**每个任务动笔前必须锁死；任一项用户未指定 = 任务不开始。** ⛔ 禁止默认跳过、禁止替用户推断（写了默认值也不行，必须把选项摆出来让用户勾）。

| **〇·1 素材来源** | ① 原创 ② 改编 ③ 对标爆款 ④ 热点速成 | 与〇·0 **正交可组合**。③④ 先挂 `sd-recon-engine`，出《对标情报卡》并经用户确认才进剧本层 |
| **A 模型版本** | ① Seedance 2.5 ② Seedance 2.0 ③ MiniMax H3（格式支线） | **三选一，无默认值**；锁定后语法契约彻底分流，禁混写 |
| **B 画幅** | 16:9 / 9:16 / 21:9（1:1 仅用户明确指定） | 与 A 同批锁定；资产板整板固定 16:9，成片画幅另行适配 |

**多段任务判定式（唯一口径）**：`目标成片时长 ÷ A 锁单段上限 > 1` 即多段任务。

**动作强度三档（与 A/B 同批定档）**：`R1 写实克制` / `R2 商业高燃（默认）` / `R3 玄幻大招`。

## 四、硬门 ③：交付纪律

1. **对外最多 3 件**：① 主文档（md 或看板，按 C 锁）② 看板 HTML（仅 C 含看板）③ **《预演故事板》md（P4.5 · 默认必出）**。超过 3 件 = 交付层违规。
2. **md 正文只放两样**：**资产提示词 + 分镜提示词**。IP 圣经 / 故事圣经 / 锚卡 / 分集规划 / 圆桌审核 / 质检报告 / 情绪锚点表 / 导演稿 = **内部档案**（独立文件、前缀 `_内部_`）。
3. **内部术语不外泄**：交付稿里出现「世界锚卡 / 人物锚卡 / 分集规划 / 圆桌 / P0A / M1 / C27」这类词即视为泄漏（出看板时按看板口径承载全貌，此分层不适用）。
4. **命名全中文**：目录、文件名、标题一律中文；集数写「第01集」；技术标识（Seedance 2.5 / 9:16 / 图号）保留原文以对齐机检指纹。
5. **只出提示词不出图**：除用户**逐次明确下达**「出图 / 生成图片 / 跑图」口令，一律不调用出图能力；用户追问「怎么还没出图」≠ 授权。

**P4.5 条件硬门（CT5-P45）**：① 单段【站位声明】具名 ≥3 人同框 ② 全集 ≥2 个不同 `@//scn/` 场景 ③ 单段内跨 2 场——任一命中而不附 = 契约 FAIL。可免但**必须在主稿写明理由**，⛔ 禁静默跳过。
权威：`short-drama-director/references/delivery-pitfalls.md`、`sd-storyboard-engine/references/p45-previs-storyboard.md`。

### 6.3 点名直入的作业规程（5 条，不得省）

1. **先读该 `RULES.md` 的 §一 角色定位 + 自带自检清单**，不要凭本节的一行摘要去创作（摘要只用于路由，不是规则）。
2. **直入 ≠ 免锁**：A 模型 / B 画幅 / C 交付形态 / D 段缝 / I 画风仍未定时，**先按 §二 把锁问齐再动手**；只有 〇·0 赛道与 〇·1 素材来源可由总控软推断（且须首行说明）。
3. **直入 ≠ 免形态与纪律**：§三 素材形态（M0/M1/M2）、§四 交付纪律（对外 ≤3 件、正文只放资产+分镜提示词）**在子技能里同样生效**。
4. **产物回主流**：子技能只交本阶段产物（资产→P3、分镜→P4、投喂→P5），⛔ 不得在子技能内"直接交成片提示词"绕过投喂/质检（本身即投喂/质检者除外）。
5. **跨域需求由总控补齐上游**：如"打戏但没资产"，先让 P2 出资产，**不许子技能临时发明角色外观/场景**；冲突时按 §6.5 裁决。

### 6.4 常用口令（等价旧版子技能快捷调用）

`/写剧本` `/台词诊断` `/微表情` `/表演档案` `/语速自检` `/做分镜` `/生成视频提示词` `/H3提示词` `/导出工作流参数` `/情绪曲线` `/看板` `/审查` `/拉片诊改` `/数字资产包` `/素材形态` `/接线单` `跳过确认，直接出整集` —— 各口令的完整路由表见 `short-drama-director/RULES.md` 指令路由节。

### 6.5 权威归属原则（冲突时按此裁）

- 通用结构门（画幅 / 时长 / 字段 / 时间轴 / 机检码）：**以总控 `short-drama-director` 为准**；
- 领域规则（打斗动作、玄幻术法、真人受力、剧本链、解说语速、海外语言合同）：**以对应子技能为准**；
- 锁系统、素材形态、七段式、H3、资产编号（`图N`）：**只在总控定义，子技能不得另立**。

## 八、反模式（踩了就返工）

1. ❌ 锁没问齐就开写（尤其 A 模型 / B 画幅 / C 交付形态 / D 段缝 / I 画风）。
2. ❌ 多段任务把 D 锁推到分镜阶段（D 是**立项锁**）。
3. ❌ 用户提了某部剧名就当「原创」处理（大概率是**对标**，走〇·1 ③）。
4. ❌ 索要用户图片、因缺图卡住流程、写不存在的图号、声称「已核验」却没看过图。
5. ❌ 只读总控、不读子技能模板，凭印象手搓资产/分镜（字段必然缺失）。
6. ❌ 把中间工作文件当交付物逐件落盘（一次任务产出十几个文件）。
7. ❌ 单批写到 8k 之后开始「同上 / 其余同理 / 省略若干条」。
8. ❌ 整份多段稿送检（不 `--by-segment`）导致打戏档误判、时长与占比失真。
9. ❌ 把「机检全绿」当任务完成，不跑交付契约核销。
10. ❌ 交付稿里出现内部术语与人名风格词（选项层可用名字，交付层绝不出现人名/工作室/影片名）。

> 「开工前先把六件事定下来：**做哪类（国内剧/海外剧/解说/其他）· 素材从哪来（原创/改编/对标/热点）· 哪个模型（Seedance 2.5 / 2.0 / H3）· 什么画幅（16:9 / 9:16 / 21:9）· 交付形态（看板 / md / 都要）· 段缝怎么接（末帧承接 / 换机位硬切 / 空镜 / 技巧转场，仅多段任务）**，再挑一个画风卡（也可选「按你的推荐走」）。这七项定了我就直接跑完剧本、资产、分镜、投喂稿和质检，中途只在剧本 / 资产 / 分镜 / 投喂四个门停一下。」
