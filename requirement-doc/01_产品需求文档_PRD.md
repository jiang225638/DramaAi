# DramaAI 产品需求文档（PRD）

- **产品名称**：DramaAI（基于开源项目 Toonflow 二次开发）
- **产品形态**：Windows / macOS 跨平台桌面客户端（BYOK 买断制 / 周期授权制）
- **当前版本规划**：v1.0.0（对应上游基线 v2.0.x）
- **文档状态**：已评审定稿

---

## 一、背景与商业定位

### 1.1 项目背景
AI 短剧与动态漫制作正处于爆发期，但市面上主流的 SaaS 创作平台普遍采用“月租订阅 + 按次消耗算力点数”的模式，创作者试错成本极高；同时，若个人开发者自建公网 SaaS 平台，则面临巨额算力垫资、防羊毛党风控、以及国内 ICP/算法备案/微短剧分类备案等极高合规门槛。

**DramaAI** 采用 **BYOK（Bring Your Own Key，自带密钥 / 自带本地算力）独立桌面客户端**模式：只售卖软件工具授权（卡密），用户自行配置高性价比第三方 API Key 或调用本机独立显卡（ComfyUI），实现开发者 **0 算力垫资成本、0 平台内容合规风险** 的轻资产商业闭环。

### 1.2 核心商业拷问：上游开源免费，用户凭什么为 DramaAI 付费？
由于上游项目采用 MIT 协议开源且提供免费安装包，**单纯换皮改名无法构成长期付费壁垒**。DramaAI 的核心付费价值主张（Value Proposition）必须建立在**“省钱、省时间、开箱即用”**的增量价值之上：

| 维度 | 原版开源工具痛点 | DramaAI 付费版核心增量价值 |
| :--- | :--- | :--- |
| **配置门槛** | 需自行寻找 API 文档、手动编写模型协议与参数规则，小白极易报错卡死 | **内置国内外高性价比模型一键预设**（硅基流动、可灵、海螺、OpenAI、Fal.ai 等），粘贴 Key 即用 |
| **算力成本** | 默认引导至官方合作充值渠道或第三方中转站 | **直连本机 ComfyUI 免费算力节点**，支持 RTX 显卡用户 0 边际成本无限出图生视频 |
| **内容生产效率** | 空白画布起步，缺乏成熟的短剧工程模板 | **随包附赠爆款短剧工程模板与分镜提示词库**（男频逆袭、女频穿书、出海狼人/豪门复仇等） |
| **隐私与纯净度** | 默认开启官方遥测数据上报、内置多处官方商业账号与赞助推广链接 | **100% 本地隐私纯净版**，彻底切断外部遥测上报与推广干扰，数据完全留在本地 |
| **服务与交付** | 社区自助爬坑 | **提供配套实操视频教程 + 买家专属交流群答疑 + 稳定版本维护** |

## 二、目标与非目标（Goals & Non-Goals）

### 2.1 产品目标（Goals）
1. **完成品牌独立与合规改造**：以 `DramaAI` 独立品牌发布，同时严格遵守 MIT 许可证要求（保留原始版权声明）。
2. **彻底切断上游在线依赖与隐私外泄**：关闭向原作者服务器（`api.toonflow.net`）发送的遥测统计、版本检查与账号请求。
3. **构建高可靠、零服务器成本的卡密授权体系**：支持买断卡、月卡、年卡激活，具备机器码绑定、离线容灾运行与自助换机解绑能力。
4. **打造“开箱即用”的创作体验**：让非技术背景的短剧创作者在 3 分钟内完成 API 配置并跑通第一个分镜剧本。

### 2.2 非目标（Non-Goals —— 本阶段明确不做）
1. **不做公网多租户 SaaS 平台**：不开启多租户注册充值系统，不代管用户资产与作品文件。
2. **不做 API 算力中转与代充值**：不碰用户的 API 账单，避免资金池风险与信用卡拒付风险。
3. **不重造画布与底层 Agent 引擎**：最大化复用上游优秀的无限画布与节点架构，保持低侵入解耦以便持续合并上游新功能。

## 三、目标用户画像与用户故事

### 3.1 目标用户画像
- **画像 A（副业创作者 / 小说推文博主）**：不懂编程和复杂 API 参数，想把网文快速转成动态漫发抖音、快手、TikTok 赚取流量分成或推文佣金。
- **画像 B（小型短剧工作室 / B2B 代制作人员）**：手头有 RTX 3060/4070/4090 显卡电脑，对云端按次扣费极其敏感，希望一套本地工作流批量稳定出片。

### 3.2 核心用户故事（User Stories）
- **US-01（激活与试用）**：作为新下载的用户，我希望能看到清晰的激活引导界面，输入在发卡平台购买的卡密后 1 秒内解锁全部功能；在我出差断网时，已激活的软件依然能正常打开创作。
- **US-02（换机解绑）**：作为付费买断用户，当我更换新电脑或重装系统时，我可以在旧电脑上点击“解绑本机”释放名额，并在新电脑上重新激活。
- **US-03（极简配 Key）**：作为不懂技术的小白用户，我打开设置面板时，能直接从下拉列表中选择“硅基流动 / DeepSeek / 可灵”，只需粘贴一串 API Key 并点击“测试连接”，系统就自动帮我配好所有模型参数。
- **US-04（本地免费算力）**：作为拥有独立显卡的用户，我希望能在画布中直接拖出“本地 ComfyUI 节点”，填入本地端口即可免费批量生成角色图和分镜。

## 五、定价与销售渠道策略

### 5.1 统一发货模式（与自建 Cloudflare 卡密库对齐）
为保证卡密全部由自建 Cloudflare D1 数据库统一签发与管控，**所有国内外销售渠道均采用“预生成卡密池 ➔ 平台自动发卡”模式**：
- **国内渠道**：面包多、爱发电、微伴/独角数卡发卡网、闲鱼/淘宝自动发货。
- **海外渠道**：Gumroad / LemonSqueezy（开启自定义 License Key 列表导入或 Webhook 自动调取发卡接口）。

## 六、风险评估与应对预案

| 风险项 | 风险等级 | 应对措施 |
| :--- | :---: | :--- |
| **本地客户端被逆向修改绕过前端弹窗** | 中 | 采用“前端 UI 守卫 + 本地内嵌 Server 路由中间件验签”双层校验，核心 AI 生成与文件导出接口均在后端校验签名 Token，提高篡改门槛。 |
| **用户重装系统或更换硬件导致机器码变化** | 高 | 1. 使用 Windows 注册表 `MachineGuid` / macOS `IOPlatformUUID` 作为稳定指纹；<br>2. 提供客户端内“自助解绑”按钮；<br>3. 管理端预留人工重置设备绑定接口，售后 10 秒内可帮客户解绑。 |
| **上游开源项目大版本重构导致合并冲突** | 中 | 严格执行“外挂式低侵入开发”：所有卡密、预设代码独立存放于专属目录，对原项目文件仅做单行挂载引用。 |
